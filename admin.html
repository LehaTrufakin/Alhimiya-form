Админка ярмарки

Здесь можно менять мастерские, товары, фото и модели — всё сохраняется прямо на сайт.

Как получить ключ (один раз, 3 минуты)
  1. Откройте github.com/settings/personal-access-tokens/new (войдите в GitHub).
  2. Token name: например «админка ярмарки». Expiration: срок действия — можно 1 год.
  3. Repository access → Only select repositories → выберите Alhimiya-form.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Внизу Generate token и скопируйте ключ (начинается с github_pat_) — GitHub покажет его только один раз.
  6. Вставьте ключ сюда. Он хранится только в этом браузере и даёт доступ только к этому репозиторию.

Никому не передавайте ключ. Если потеряли телефон или ноутбук — удалите ключ на той же странице GitHub и создайте новый.
