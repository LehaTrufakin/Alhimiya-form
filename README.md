# 3D-витрина: инструкция

## Что в архиве
- `index.html` — код витрины, его менять не нужно.
- `products.js` — ваши настройки и товары, правите только его.
- `README.md` — эта инструкция.

Сюда же положите свою 3D-модель, например `model.glb`.

## 1. Модель
Формат: **GLB** (glTF Binary), он хранит цвета. Модель желательно не тяжелее 5–10 МБ.
STL тоже откроется, но без цвета. Для него в товаре укажите `color: '#c0563f'` и `material: 'clay'`, `'resin'` или `'glossy'`.

## 2. Настройки (products.js)
Откройте файл в Блокноте. Впишите название мастерской, ссылки на группу ВК и данные товара.
Меняйте только текст внутри кавычек и не удаляйте запятые.

## 3. GitHub Pages
1. На github.com: **+ → New repository**, имя `vitrina`, **Public**, **Create**.
2. **uploading an existing file**: загрузите `index.html`, `products.js` и модель, затем **Commit changes**.
3. **Settings → Pages**: Branch **main**, **/(root)**, **Save**.
4. Через 1–3 минуты появится адрес: `https://ваш-ник.github.io/vitrina/`

Если открыть `index.html` двойным щелчком с компьютера, модель не загрузится: браузер блокирует локальные файлы. Проверяйте модель на GitHub.

## 4. Ссылки
- Каталог: `https://ваш-ник.github.io/vitrina/`
- Сразу 3D товара: `https://ваш-ник.github.io/vitrina/#tovar-1`
- QR-этикетки: `https://ваш-ник.github.io/vitrina/#labels`

## 5. Изменения
Откройте на GitHub `products.js`, нажмите ✏️, исправьте и нажмите **Commit changes**.
Новая модель загружается через **Add file → Upload files**.

## Если модель «лежит на боку» (только для STL)
В товаре добавьте `zUp: false`.
