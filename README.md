# Электронная ярмарка мастеров

## Файлы
- `index.html` — код, не меняется
- `fair.js` — настройки ярмарки: мастерские, их товары, пустые места
- модели `.glb` всех мастерских лежат рядом

`products.js` больше не нужен: если есть `fair.js`, витрина работает как ярмарка.
Старые ссылки вида `…/#tovar-1` продолжают открываться.

## Ссылки
- Ярмарка (главная): `https://lehatrufakin.github.io/Alhimiya-form/`
- Витрина мастерской: `…/#alhimiya`
- Товар: `…/#alhimiya--tovar-1`
- QR-этикетки всех товаров: `…/#labels`

## Как сдать место новой мастерской
1. В `fair.js` замените любой `{ empty: true },` на блок мастерской (скопируйте блок «Алхимии форм»).
2. Задайте ей свой `id` латиницей (например `snezhnaya-lavka`), название, ссылку на её ВК и цвет навеса.
3. Модели мастерской загрузите на GitHub. Чтобы имена не пересекались, добавляйте приставку: `lavka-zvezda.glb`.
4. Commit changes. Через 1–2 минуты мастерская появится в рядах.

## Фото торговых рядов (необязательно)
1. Загрузите фото, например `ryady.jpg`, и укажите в `fair.js`: `photo: 'ryady.jpg',`.
2. Каждому месту добавьте `x` и `y`: где на фото поставить кнопку, в процентах от левого и верхнего края. Например, `x: 25, y: 60,`.
Нарисованные ряды под фото остаются, по ним тоже можно переходить.
