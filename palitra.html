Справочник цветов для ярмарки

Нажмите на цвет — код скопируется. Вставьте его в настройки между кавычками, например pageColor: '#3a1630',

Где какие цвета:
pageColor — фон страницы (в fair.js — у ярмарки, в shops/имя.js — у мастерской)
pageText — цвет заголовка на этом фоне. Тёмный фон → светлый текст, светлый фон → оставьте ''
color — цвет полосатого навеса лавки (в файле мастерской)
colorTop / colorBottom / textColor — шапка ярмарки (блок header в fair.js)

Готовые сочетания: фон + текст

Кнопка копирует сразу обе строки — вставьте их в файл мастерской вместо старых pageColor и pageText.

Светлые фоны

Для pageColor. Текст оставляйте тёмным: pageText: ''

Тёмные фоны

Для pageColor. Обязательно задайте светлый pageText — подходящие ниже.

Для pageText и textColor в шапке.

Цвета навесов лавок
